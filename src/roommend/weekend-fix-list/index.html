The Saturday list / 01

Which home jobs fit this weekend?

Start with the job you care about most. This planner walks down your list and keeps the jobs that fit the time you actually have.

Write up to eight jobs, with the most important first. Include getting materials and tidying up in each estimate.

Use the leftover minutes

If a job doesn’t fit, it goes on the next-session list. The planner still checks the shorter jobs below it. Want to save the time for a bigger job instead? Move that job to the top and give it a longer session.

For routine household planning. This tool uses your estimates; it doesn’t assess urgency or decide whether a repair is safe. Entries stay in this tab and clear when you reload.

Keep a fix list by room

RoomMend lets you photograph an issue, add it to a room’s fix list, and mark it done. The time-fitting exercise above is a separate browser tool.
