MAKE THE RESULT USEFUL

A locator is useful only if someone can use it.

  1. Location: identify where the current copy is kept. Avoid scattering duplicates without dates.
  2. Permission: ask the record owner who may see it. Knowing a password is not the same as having permission.
  3. Currency: check the date or version. Choose a review habit that suits the household.

This narrow checklist does not tell you which records you must keep, establish legal access or certify that a plan is complete. Keep sensitive details in a place you trust.
